# HatoFi — Frontend

## Requisitos

- **Node.js**: Versión 18.18.0 o superior (recomendado Node.js 20 LTS o 22 LTS).
- **npm**: Versión 9 o superior (incluido con Node.js), o alternativamente **pnpm** / **yarn**.
- Navegador web moderno (Chrome, Brave, Edge, Firefox o Safari).

---

## Instalación

1. Clonar el repositorio (si aún no lo has hecho):
   ```bash
   git clone https://github.com/hatofi/Documentacion_proyecto.git
   cd Documentacion_proyecto
   ```

2. Entrar a la carpeta del frontend e instalar las dependencias:
   ```bash
   cd hatofi-frontend
   npm install
   ```

---

## Cómo correrlo

1. Ejecutar el servidor de desarrollo:
   ```bash
   npm run dev
   ```

2. Abrir el navegador en la siguiente dirección:
   ```text
   http://localhost:3000
   ```
